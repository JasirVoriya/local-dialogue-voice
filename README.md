# 本机台词配音工具

在这台 Apple Silicon Mac 上，用本地视频的声音生成新台词音频。工具不上传视频，不会导出或改动视频。

## 启动

1. 双击 `启动.command`。
2. 首次启动会建立独立 Python 环境并安装运行依赖。
3. 在网页里导入参考视频，点击“识别视频台词”，校对整段原声和选中的参考句。
4. 在视频下方拖动绿色两侧把手，选中要模仿的语气片段；粘贴新台词后点击“生成完整音频”。
5. 试听整段或逐句试听。对某一句不满意时可点“单独重做”，其他句子会保留。
6. MP3 默认保存在本工具文件夹的 `outputs/`。

首次使用会从 ModelScope 下载本地语音模型，需要联网和数 GB 的磁盘空间；模型安装后，转写和语音生成都在本机完成。

## 系统要求

- Apple Silicon Mac，macOS；本工具默认使用 Python 3.12。
- 已安装 `uv` 与 FFmpeg。若缺少 FFmpeg，在终端运行 `brew install ffmpeg`；若缺少 `uv`，按启动窗口中的链接安装。
- 建议预留至少 12 GB 磁盘空间用于环境和模型。

## 隐私与清理

- 网页服务只监听 `127.0.0.1`。
- 上传的视频、提取的原声、转写和分句音频保存在 `~/Library/Application Support/TaiCiPeiyin/`。
- 完成后可点“清理当前项目”删除该项目的视频、临时音频和本次 MP3；导出的 MP3 也可在 `outputs/` 手动管理。
